# Overview
Hi, my name is Clifford Lin and I'm an incoming Queen's Engineering student with an interest in electrical engineering for aerospace applications. Each phase for my project targets specific goals and will be listed at the beginning of each section. The end goal is to create a working quadcopter with a fully custom flight computer.
